# Demo screenshots

Captured directly from the built-in VS Code Markdown Preview using Gnuplot Markdown Preview 0.2.0 and `examples/demo.md`. These are real application screenshots, not generated mockups.

- `functions.jpg`: sine and cosine (README opening example).
- `inline-data.jpg`: the inline squares dataset.
- `3d-surface.jpg`: the radial sine surface.

To update, open the demo in the dedicated Gnuplot Marketplace Test profile, choose Open as Preview, frame each section, and capture the app window. Keep unrelated windows and personal information out of the frame.
